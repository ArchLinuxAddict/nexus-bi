# Configuration map

- `mission_policy.json` — mission categories and training policy.
- `dataset_registry.json` — active dataset registry; currently the real-world shared-object catalog.
- `realworld_candidates_500.json` — permissive GitHub candidates.
- `realworld_candidates_new.json` — candidates not already ingested.
- `acquisition_projects.json` — acquisition project metadata.

The v4/v5 run configurations and their datasets have been removed. A v6 tool-first training config will be added only after the real-world corpus and tool baselines are frozen.
